# 校园网自动登录 · Campus Auto Login

<img src="assets/app-icon.png" width="72" height="72" alt="校园网应用图标">

一个 Windows 校园网登录小工具：填写一次账号、密码和运营商，登录 Windows 后自动打开校园网认证页，完成填写和登录。

**当前版本尚未完成真实密码登录验证。** 已读取目标校园网的 Dr.COM 页面、脚本和登录模板，确认输入框及运营商下拉选项，并通过本机加密和模拟网页测试。当前设备的校园认证查询结果为已在线，因此没有执行退出或重新登录。

## 功能

- Material 风格的浅色中文界面，支持密码显示、连接状态提示和独立运行记录。
- 配置账号、密码及运营商，支持高 DPI 显示。
- 独立应用图标，含 Windows 16–256 像素多尺寸图标。
- 登录 Windows 后在后台运行，最多等待校园网络就绪 10 分钟。
- 调用现有 Edge，未安装时尝试 Chrome；独立临时浏览器配置不会改动日常浏览器资料。
- 操作原登录页的输入框和按钮，由网页自身执行认证逻辑。
- 支持普通下拉框、单选框及部分自定义运营商下拉菜单。
- 使用 Windows DPAPI 加密保存账号密码，不保存明文密码到配置文件。
- 已能访问互联网或校园认证显示已在线时跳过登录，每次运行最多提交一次。
- 识别到验证码、无法选择运营商或页面跳往其他主机时停止。
- 支持关闭开机登录和删除本机账号配置。

## 使用方法

1. 将 `CampusAutoLogin.exe` 放到一个固定文件夹，避免之后移动或删除。
2. 连接校园 Wi-Fi 或插入校园网网线。Windows 的 Wi-Fi 自动连接需要提前设置好。
3. 双击程序，按平时登录网页时的写法填写账号、密码。
4. 按实际账号选择“中国移动”“中国电信”“中国联通”或“教师专用”。如果网页默认选项已经正确，可以留空。
5. 保持勾选“开机自动连接”，点击“保存并连接”。
6. 看到外网验证成功或校园认证已在线提示后关闭程序。下次登录 Windows 自动运行。

首次测试建议勾选“显示登录浏览器”，方便查看网页提示。第一次完成真实密码登录测试后再依赖开机登录。

这是用户登录 Windows 后运行的程序，不是在 Windows 登录界面之前联网。开机任务结束后进程退出，不提供全天断线重连；从睡眠恢复后可再次打开程序测试登录。

## 当前适配地址

```text
http://10.0.253.14/?url=http://www.msftconnecttest.com/redirect
```

用户提供的 `1.htm` 当前为注销页，因此程序使用门户首页，根据在线状态显示相应页面。程序固定限制在 `10.0.253.14` 页面内填写账号密码。若学校升级地址或跳转到另一认证主机，需要先修改源码中的 `PORTAL` 与 `HOST`。

不预设运营商后缀，也不猜测认证接口。账号是否需要后缀，由学校原网页的规则决定。

## 配置与隐私

本机数据存放在：

```text
%LOCALAPPDATA%\CampusAutoLogin_10_0_253_14\
├── account.dat   # Windows DPAPI 加密的账号、密码、运营商
└── status.log    # 运行状态，不记录账号密码或网页内容
```

- 加密绑定当前 Windows 用户，不能直接复制到另一台电脑或另一 Windows 用户下使用。
- 同一 Windows 用户下运行的其他程序仍可能调用 DPAPI 解密；它不能防御已经控制该用户会话的恶意软件。
- 密码只填入配置的校园网登录页；原页面采用 HTTP，传输保护取决于校园认证页面自身。
- 临时浏览器使用结束后关闭，并尝试清理临时资料。
- GitHub 仓库不包含任何真实账号密码或本机配置。

开机项位于当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，名称为 `CampusAutoLogin_10_0_253_14`。不需要管理员权限。

## 故障排查

| 提示 | 处理方法 |
| --- | --- |
| 无法访问 10.0.253.14 | 确认连到校园网络，检查 VPN/代理或网卡路由。 |
| 没有找到运营商 | 按网页完整名称填写，或保留网页默认选项并将运营商留空。 |
| 没有识别到表单/登录按钮 | 勾选显示浏览器，查看实际页面；定制页面需要适配选择逻辑。 |
| 已提交但未验证联网 | 查看网页提示并核对账号、密码、运营商；也可能是联网探测被阻挡。程序不会自动反复提交。 |
| 检测到验证码 | 手动完成网页登录。程序不自动处理验证码。 |
| 程序移动后没有自启 | 在新位置打开程序，再次保存设置以更新开机项。 |

外网检测使用微软的 `connecttest.txt`，必须返回预期正文才判定外网连通。程序还会读取原网页脚本使用的 `/drcom/chkstatus` 在线状态接口；校园认证已在线但微软探测失败时，会分别说明两种状态并跳过重复登录。两个检测都失败时，提示未验证联网。

## 关闭与卸载

打开程序，取消勾选开机登录并点击“保存设置”，即可保留账号但关闭自启。

点击“清除配置”会删除加密账号配置、关闭自启；之后可以删除程序文件。状态日志保留在上述数据目录中，不含账号密码。

## 从源码运行

需要 Windows 10/11、Python 3.11 或更新版本（含 tkinter）以及 Edge/Chrome。

```powershell
python -m pip install -r requirements.txt
python campus_auto_login.py
```

仅执行一次后台登录：

```powershell
python campus_auto_login.py --auto
```

从源码设置自启后，应保持 Python 环境和源码路径不变。推荐日常使用打包版。

## 打包

```powershell
python -m pip install -r requirements-build.txt
python -m PyInstaller --noconfirm --clean --onefile --windowed --collect-all customtkinter --add-data "assets;assets" --icon assets/app-icon.ico --name CampusAutoLogin campus_auto_login.py
```

生成文件为 `dist/CampusAutoLogin.exe`。它依赖系统已有的 Edge/Chrome，不需要额外安装 Python。

## 验证

```powershell
python -m unittest discover -s tests -v
```

测试使用虚构账号、本机临时网页和临时配置目录，不会提交校园网认证，也不改动真实开机项。

已验证：DPAPI 加解密、配置文件不含明文口令、特殊字符账号密码、运营商下拉框/单选框/自定义菜单、验证码停止、其他主机停止、已联网或校园已认证时跳过、失败时只提交一次、界面构建，以及按真实 Dr.COM 表单结构构建的脱敏测试页。

已只读确认：目标服务器可达、Dr.COM 页面与脚本、登录模板的 `DDDDD` / `upass` / `ISP_select` 控件及运营商选项、当前设备的校园认证在线状态。

未验证：真实账号密码提交、离线后门户页面切换、实际重启后的网络时序。此项目不承诺通用兼容所有校园网。
